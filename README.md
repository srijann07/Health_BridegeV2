# HealthBridge V2 — Development Workspace

> **Development workspace / archive.** The polished, recruiter-facing HealthAI implementation is [`healthai-deploy`](https://github.com/srijann07/healthai-deploy).

This repository contains an intermediate HealthBridge V2 workspace and development artifacts created while iterating on the project.

## Repository status

This is **not the primary portfolio repository**. It is kept as a record of the V2 development work and experimentation.

The repository contains worktree-style development material, implementation notes, and intermediate project files. For a clean overview of the finished system, start with the current HealthAI repository.

## Current project

**HealthAI — AI-Powered Early Health Risk Detection System**

- Backend: Python / Flask
- Database: SQLAlchemy with MySQL support
- Authentication: JWT + bcrypt
- AI/analysis: health-risk assessment engine
- UI: Bootstrap-based web interface
- Testing: pytest
- Deployment: Docker / cloud deployment configuration

➡️ **Primary repository:** [`healthai-deploy`](https://github.com/srijann07/healthai-deploy)
